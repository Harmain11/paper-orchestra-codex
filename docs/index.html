Frequently asked
What this does—and doesn't do.
Is this an official Google or OpenAI product?
No. This is an independent community integration. It uses Google's separately licensed PaperOrchestra repository; neither Google nor OpenAI has endorsed the wrapper.
Can it generate a paper without an API key?
The prepare and audit features run offline. The upstream PaperOrchestra generation pipeline normally needs model-provider credentials and may incur costs.
Will it improve model accuracy or validate my claims?
No. It preserves and checks evidence files, but verification of experimental design, p-values, citations, and conclusions remains a researcher responsibility.
Does installing the plugin send my data anywhere?
No. A user must explicitly approve cloning upstream or running the writing pipeline. If you execute upstream generation, research content may be sent to your selected provider.
Can I run it without Codex?
Yes. The Python standard-library bridge can run standalone. See the main README for command descriptions, input layout and testing instructions.
